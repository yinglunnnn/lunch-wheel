# 規格書：今天吃什麼？午餐決策轉盤 (Lunch Wheel)


一、專案概述

1. 專案名稱：今天吃什麼？午餐決策大輪盤

2. 專案背景：現代外食族與學生在午休或用餐時間，經常面臨「午餐選擇困難症」，在眾多選項中反覆猶豫而耗費時間與精力。

3. 核心目標：開發一個輕量、有趣且直覺的單頁式網頁應用程式，透過動態轉盤隨機抽籤與情境標籤過濾，在 10 秒內協助使用者迅速做出決定。

4. 部署平台：GitHub Pages 靜態網頁託管。

二、技術架構與環境

1. 程式架構：單一檔案架構 (index.html)，整合 HTML5、CSS3、Vanilla JavaScript。

2. 核心技術：

。 HTML5 Canvas API：繪製自適應角度扇形輪盤、文字排列與物理動態旋轉。

。 Browser LocalStorage API：瀏覽器端儲存自訂選項清單，重整頁面不遺失資料。

。 Canvas-Confetti CDN：提供開獎瞬間的全螢幕動態紙花彩蛋特效。

。 Google Fonts (Zen Maru Gothic)：提供圓潤柔和的視覺字體。

3. 支援環境：相容主流現代瀏覽器（Google Chrome、Apple Safari、Microsoft Edge、Mozilla Firefox），支援行動裝置與電腦版瀏覽。

三、視覺設計規範 (UI/UX)

1. 設計風格：活力俏皮黃色系 (Playful Warm Yellow & Orange)。

2. 配色規劃：

。 頁面背景色：柔和奶油黃 (#FFF9E6)，營造明亮且護眼的溫暖氛圍。

。 主要裝飾與按鈕色：活力芝士黃 (#FFD23F)、夕陽暖橘 (#FF7B54)。

。 文字與邊框色：深焙咖啡棕 (#3D2C1D)，取代死黑線條，增加插畫風格質感。

。 扇形隨機跳色：粉橘、薄荷綠、天藍、柔粉、淡紫等多色活潑馬卡龍配色。

3. 佈局架構：

。 電腦版：採雙欄並排設計，左側為輪盤旋轉核心區，右側為情境篩選與自訂項目清單。

。 行動版：採單欄直式流式排列，輪盤自動縮放至螢幕寬度，下方依序排列操作面板。

4. 視覺細節：

。 元件採大圓角 (Border Radius 24px 以上)。

。 外框採 2 至 4px 深色粗描邊，並具備按壓位移之立體微陰影。

四、詳細功能規格

1. 動態旋轉輪盤模組

。 動態扇形分割：系統依目前有效項目數量 (N)，即時計算並繪製等分扇形 (角度為 2PI / N)，自動填入餐點名稱與顏色。

。 物理旋轉動畫：點擊「開始轉盤」按鈕後，輪盤旋轉 3.8 秒，套用三次方減速公式 (Ease-Out Cubic)，模擬真實輪盤由快變慢的物理阻尼減速效果。

。 頂部指針與判定：指針固定於輪盤正上方 (270 度位置)，旋轉結束後精確計算停止角度所對應的扇形項目。

。 防重複點擊：旋轉進行期間自動鎖定按鈕為不可點擊狀態 (disabled)，動畫完全結束後方解除鎖定。

。 項目不足警示：若目前分類項目少於 2 項，系統會自動在畫布中央顯示提示，並停用旋轉按鈕。

2. 情境分類篩選模組

提供 4 組即時切換標籤按鈕：
(1) 全部選項：載入所有儲存的美食清單。
(2) 銅板百元：聚焦於便當、牛肉麵、水餃、滷肉飯等親民料理。
(3) 清爽低負擔：聚焦於健康餐盒、生菜沙拉、越式河粉、輕食豆漿。
(4) 犒賞聚餐：聚焦於日式拉麵、義大利麵、韓式料理、美式漢堡、火鍋。

點擊標籤後，輪盤與右側候選清單會以微秒級速度即時重繪並更新。

3. 自訂候補清單管理模組

。 新增項目：使用者可透過文字輸入框輸入料理或店名（限制 12 字內），點擊新增或按 Enter 即可動態加入目前清單，並自動分配調色盤顏色。

。 刪除項目：每個項目右方具備獨立刪除按鈕 (✕)，點擊即可移出輪盤。

。 本地儲存：每次新增或刪除操作皆會立即自動寫入 LocalStorage，關閉瀏覽器或下次重開皆保留最新清單。

。 一鍵還原：提供「恢復預設推薦選單」按鈕，點擊並確認後可重新載入系統內建的推薦項目。

4. 開獎結果回饋與後續行動模組

。 彈出視窗：輪盤完全停定後，彈出圓角卡片展示獲選品項名稱，並具備彈跳進場動態效果。

。 慶祝特效：同步觸發全螢幕繽紛紙花粒子特效 (Confetti)，增強遊戲化正向回饋。

。 地圖串接：視窗內建「在 Google Maps 搜尋附近店家」按鈕，點擊後會以新分頁開啟 Google 地圖，並自動帶入獲勝品項名稱作為搜尋關鍵字。

。 關閉與重抽：提供「就吃這個」確認按鈕，或點擊遮罩背景即可關閉彈窗，恢復初始狀態以供再次旋轉。

五、非功能性需求

1. 效能要求：網頁載入時間在正常網路環境下小於 1 秒；旋轉動畫渲染幀率維持 60 FPS，無卡頓現象。

2. 零外部伺服器依賴：除基礎 CDN 資源外，無須後端資料庫或伺服器運算，降低維護成本與斷線風險。

3. 可靠性：針對輸入空白字元、重複項目、過長字串均進行邏輯防呆檢查，確保程式穩定運作。
